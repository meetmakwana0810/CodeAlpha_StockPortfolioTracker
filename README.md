# CodeAlpha Stock Portfolio Tracker

A simple Python-based stock portfolio tracker developed as part of the CodeAlpha Python Programming Internship.

## 📌 Project Overview

This project allows users to enter stock symbols and quantities to calculate the total investment value of their portfolio.

The program uses a predefined dictionary containing stock symbols and their prices. Users can add multiple stocks and view a complete portfolio summary at the end.

## 🎯 Features

- Display available stocks and their prices
- Enter stock symbols manually
- Enter the quantity of each stock
- Calculate investment value for each stock
- Calculate total portfolio investment
- Handle invalid stock symbols
- Handle invalid quantities
- Display a portfolio summary
- Console-based interface

## 🛠️ Technologies Used

- Python
- Dictionary
- Lists
- Loops
- Conditional statements
- Functions
- User input/output
- Basic arithmetic
- Exception handling
